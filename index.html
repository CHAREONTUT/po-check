อัปโหลด Excel เพื่อเพิ่ม/อัปเดต PO หรืออัปเดต EAS เดือนใหม่
📌 รูปแบบ Header ที่ต้องใช้ใน Excel:
PO No. | DM | Start | End | Item | Name | EAS No | EAS Month
• 1 แถว = พนักงาน 1 คน ใน 1 ช่วงเวลา
• Start/End = วันเริ่ม-สิ้นสุดของพนักงานคนนั้นในช่วงนั้น
• EAS No + EAS Month = ถ้ากรอกจะบันทึก EAS Placed ให้อัตโนมัติ
• EAS Month รูปแบบ: 01-31/03/2026 หรือ 2026-03
• PO No. กรอกแค่บรรทัดแรกของแต่ละ PO

PO No. | Name | EAS No | EAS Month
• PO No. และ Name ต้องตรงกับที่มีในระบบแล้ว

• ถ้าเดือนนั้นมี EAS อยู่แล้ว ระบบจะอัปเดตให้อัตโนมัติ
